# EQUILIBRIUM GRAIN — Liberty Music Software

Prototype technique v0.1.0. Instrument granulaire JUCE, quatre couches, deux oscillateurs hybrides. Le moteur indépendant a été testé sous Linux ; la compilation du plugin et la fidélité graphique restent à valider.

Cibles : macOS ARM64 AU/VST3/Standalone, Windows x64 VST3/Standalone, intégration native Liberty DAW.

Les huit captures originales constituent la référence graphique stricte. Français par défaut, anglais sélectionnable, aucun chevauchement ni ascenseur sur écran 13 pouces, UTF-8. Aucun contrôle fictif ni image statique à la place de l'interface.

La version commerciale devra inclure les 100 presets réellement programmés et toutes les fonctions du cahier des charges. Ce prototype ne constitue pas une version commerciale.
