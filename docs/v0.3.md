# v0.3 — Factory library and sample import
100 deterministic category-based sound designs plus Init, using eight original synthesized source waveforms, existing FX and modulation. No external sample rights required; vocal and organic patches are synthetic approximations. Automated tests check names, distribution, audio output and sample playback; subjective sound quality still needs listening.
Personal sample import WAV/AIFF/FLAC, mono/stereo, 8–192 kHz, maximum 30 seconds per file and cumulative 128 MiB per instance for safe immutable publication. Non-destructive trim, fades, normalize, root note and existing grain controls. Project state stores external paths, not audio bytes; retain original files at their paths. Missing files are shown as missing. Existing source automation range unchanged.
Browser: 10 categories, favorites, search by name/category/tag, eight entries per page. Factory read-only; user-preset save/import/export, advanced slicing, spectral processing, motion sequencer, MPE remain future work. No modifications to the approved main layout besides new import and browser controls.
