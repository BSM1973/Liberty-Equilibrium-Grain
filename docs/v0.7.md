# v0.7 Hybrid Synthesis Pro
Two independent oscillators, ten modes: sine, triangle, saw, square, pulse/PWM, four-frame wavetable, internal sine PM/FM with ratio and index, white noise, octave-down sub and two-profile harmonic spectral synthesis. The spectral oscillator uses original additive harmonic profiles, not imported sample FFT resynthesis. Independent level, coarse/fine tune, 1–16 unison voices, detune, equal-power stereo spread, mode-specific shape, sub mix and note-fundamental hard sync. Existing cross-PM (OSC2 to OSC1) and ring mix remain. Nine harmonic-limited table tiers and conservative internal FM bandwidth cap; short reset smoothing for sync, not perfect antialiasing under hard sync/cross-PM. Config cached per render segment, immutable shared table bank initialized outside audio callback; no new audio-thread allocation. Legacy sine path selected for existing presets by default. Scope displays actual pre-mix oscillator signals when page 03 open. New continuous oscillator parameters appended to macro destinations, keeping original indices; MIDI Learn and A/B state apply. User wavetable import, sample-derived spectral oscillator, hard/soft saturation and adaptive CPU budgets are not included. Tests cover ten modes, stereo unison, spectral shapes, sync stability and full engine routing at 44.1–192 kHz; alias energy, max-polyphony real-time CPU and native visual verification remain pending.
