# v0.2.1 Filters & Effects
- Two independent stereo filters per granular layer, serial/parallel, response curves from actual coefficients. Original 6 dB low-pass and bypass preserve the v0.2 default. Resonance disabled for bypass and original mode.
- 12 serial configurable master slots: saturation, chorus, delay, stereo feedback reverb, tilt EQ, compressor, phaser, flanger, bitcrusher, Hilbert-based frequency shift, stereo imager and sample-peak limiter. Individual on/off, amount and wet/dry. Space adjusts overall wet proportion. These are initial DSP implementations, not convolution/true-peak/oversampled models.
- Two pages, no scrollbar. Fixed 4x3 rack. Existing parameter IDs retained. New effect slots empty by default; recall via APVTS.
- Tests cover filter response, impulse stability, audible changes, bypass and combined rack at four sample rates. Native UI and CI still require actual build verification.
