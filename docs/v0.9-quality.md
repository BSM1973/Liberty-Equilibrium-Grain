# v0.9 — Release quality gates
Automated: 100 factory presets through actual JUCE processor, peak/RMS/DC/nonfinite CSV, existing DSP tests, 60 seconds of audio per stress scenario at 48 kHz/128 with 16 notes (4 granular layers; two 16-unison oscillators; combined modulation/FX/spectral), short matrix 44.1/96/192 kHz at 64/256/512; mean/P95/P99/max audio-budget percentage, overruns and clipping. CPU results are diagnostic, not pass thresholds: shared CI runners cannot certify DAW real-time performance. Coherent harmonic residual measurements exclude FM, hard sync and ring; they cannot quantify all alias components. Memory test checks 100 identical reloads without retained growth, not reclamation of distinct data. State roundtrip covers parameters, MIDI mapping, macro/morph flags, random locks, preset file. UI geometry audit covers FR/EN and main subpages with 1050x700 snapshots; geometry warnings do not fail CI, but must be reviewed before release. Static source checks are not exhaustive glyph validation.
Manual release gates: listen to all 100 presets (musical quality, dynamics, distinctiveness); verify real DAW AU/VST3 recall, MPE hardware, sample paths, missing assets and portability; inspect screenshots and test physical 13-inch screen; measure 60 s real-time in target hosts with buffers 64/128/256 and sample rates 44.1/48/96 kHz. Require no audio dropouts in supported load scenarios and no unresolved UI defects before commercial packaging. Distinct sample reclamation and offline background rendering remain open. No new synthesis features.
