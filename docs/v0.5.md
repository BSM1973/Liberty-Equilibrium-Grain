# v0.5 Motion & Sequencer
Three subpages, held-note polyphonic transposition up to 64 steps, velocity/gate/probability/ratchet, swing, humanization, scale, seven arp modes. Host BPM or internal clock; note-triggered, not PPQ locked. MIDI export C4 pattern at 120 BPM when synced or internal BPM otherwise. One pattern stored in state, no chaining yet. Six XY motion destinations; custom path up to 64 points at 20 Hz; playback uses audio clock, speed and depth. Direct play/manual defaults preserve previous settings. Native build and performance not yet validated.
