# v0.8 Sample Lab & Preset Pro
- Region/Analysis subpages: autocorrelation note estimate on import, energy-rise transient detector (max 64 slices), next/previous slice sets active grain region, nearest stereo-mid zero crossing, per-grain bidirectional loop crossfade up to 100 ms. Detection is heuristic, not guaranteed for polyphonic/noisy samples. Time stretch 0.5–2x and pitch shift ±12 semitones use offline sinc resampling and stereo WSOLA; render selected region to a new WAV, then load it. Maximum 30 seconds. No destructive overwrite of original; offline render runs on message thread. Existing sample memory limit remains 128 MiB cumulative per instance.
- Custom wavetable mode per oscillator: mono/stereo audio mixed to mono, single cycle 32–8192 samples or 1–16 frames of 1024/2048/4096 samples; resample and harmonic-limit to nine 1024-point tiers. No proprietary wavetable formats or arbitrary audio analysis. 32 MiB cumulative table memory per instance. Paths/frame size restored from state.
- User browser: choose/create bank folder, save state as .egpreset, import validated file into bank without overwrite, export current state, search and paginated recall. Files contain serialized plugin state including mappings, not external audio data or spectral captures. Samples and wavetables must remain accessible at original paths. Default folder under user application data.
- Intelligent sound variations perturb curated continuous parameters only, preserve levels/pitch/source selection, active layers and enabled effect types. Lock eligible knobs/sliders via right-click. One undo level for last variation, not a general edit history. Locks saved in project/preset state.
- All previous parameter IDs retained. Tests for analysis, pitch/stretch and wavetable frame interpolation added. Native CI, listening tests, offline processing performance and 13-inch visual validation pending.
