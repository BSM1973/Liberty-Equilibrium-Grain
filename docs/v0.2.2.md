# Modulation
64 bipolar routes; eight LFOs (six wave shapes, tempo rate), eight per-voice ADSR envelopes, four 64-step bipolar generators and four per-voice function generators. 83 destinations. Global effect and drive destinations use global sources only; envelope, velocity, note and function sources are per voice for layer and oscillator destinations. Custom drawing, multi-stage envelopes, drag and drop and per-note aftertouch are not included. Matrix paginated, no scrolling. Existing LFO controls retained on LFO 1. Tests for matrix and audible route 64. Native build pending.
